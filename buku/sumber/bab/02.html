Bab 2Menyiapkan Bengkel Kerja

Sebelum menyusun blueprint pertama, kita pasang kelima skill, memastikan semuanya terbaca oleh Claude Code, lalu memeriksa bahwa skrip gerbangnya bisa berjalan di mesin Anda.

Setelah membaca bab ini, Anda dapat:
  • memasang VCBD Suite di Claude Code (lokal) maupun claude.ai;
  • memahami mengapa kelima folder skill harus bersebelahan;
  • memverifikasi instalasi dengan uji asap singkat.

2.1 Kebutuhan sistem

VCBD sengaja dibuat ringan. Seluruh skripnya hanya memakai pustaka standar Python dan Bash, jadi tidak ada pip install yang wajib.

KebutuhanUntukCatatan
Python 3.8+Semua skrip .pyHanya pustaka standar; diuji pada 3.12 dan 3.14
Bashvalidate.sh, validate-kontrak.sh, gerbang.shKompatibel bash 3.2 bawaan macOS
zipscripts/kemas.shHanya untuk membuat paket claude.ai
pymysql (opsional)reverse-vcbd membaca MySQL/MariaDBCadangan: klien mysql di PATH
psycopg2-binary (opsional)reverse-vcbd membaca PostgreSQLSQLite tidak butuh tambahan
Claude CodeMenjalankan skillCLI, aplikasi desktop, web, atau ekstensi IDE

2.2 Memasang di Claude Code

Langkah 1 Clone repositori, lalu salin isi folder skills/ ke folder skill global Anda, ~/.claude/skills/.
$ git clone https://github.com/Syamsuddin/VCBD.git
$ mkdir -p ~/.claude/skills && cp -r VCBD/skills/* ~/.claude/skills/

Gambar berikut memperlihatkan hasilnya pada mesin uji.

Memasang kelima skill ke ~/.claude/skills dan memeriksa prasyaratnya.
  1. Perintah salin. Untuk instalasi per proyek, ganti tujuannya menjadi .claude/skills/ di root proyek.
  2. Kelima folder harus muncul berdampingan dengan nama persis seperti ini.
  3. Setiap skill membawa SKILL.md (instruksi untuk agen), references/ (dibaca saat dibutuhkan), dan scripts/ (dieksekusi, bukan dibaca).
  4. Versi Python dan Bash cukup diperiksa sekali.
Langkah 2 Mulai sesi Claude Code baru. Skill baru terbaca otomatis. Bila belum muncul, keluar lalu buka lagi sesinya.

2.3 Mengapa harus bersebelahan?

Beberapa skrip dipakai lintas skill. Daripada menyalin kode yang sama ke lima tempat (yang akan melanggar prinsip "satu fakta, satu rumah"), skill di hilir mencari skrip di folder saudaranya.

SkillMemakai dari skill lain
reverse-vcbdvcbd/scripts/scaffold.py dan validate.sh
coding-vcbdvcbd/scripts/token_ledger.py dan validate.sh
review-vcbdcoding-vcbd/scripts/gerbang.sh dan meter.py
reverse-web-vcbdvcbd (lewat draf manifest)
Jebakan umum. Memasang sebagian skill saja, misalnya hanya coding-vcbd, membuat gerbang mesinnya gagal mencari validate.sh. Pasang kelimanya, walaupun Anda baru berencana memakai satu.

2.4 Menyalin skrip ke proyek

scaffold.py otomatis menyalin validate.sh dan token_ledger.py ke folder scripts/ proyek saat blueprint dibuat. Salin juga skrip coding-vcbd dan review-vcbd, supaya proyek bisa memeriksa dirinya sendiri tanpa bergantung pada folder skill:

$ cd /path/proyek
$ cp ~/.claude/skills/coding-vcbd/scripts/{meter.py,gerbang.sh} scripts/
$ cp ~/.claude/skills/review-vcbd/scripts/*.py scripts/
Selalu jalankan gerbang dari root proyek. validate.sh, validate-kontrak.sh, dan gerbang.sh membaca berkas secara relatif. Bila dijalankan dari folder lain, ketiganya melapor [FAIL] … jalankan skrip dari root proyek.

2.5 Memasang di claude.ai

Di claude.ai, skill diunggah sebagai berkas zip. Zip per skill tersedia di halaman rilis v2.6, atau bisa Anda buat sendiri dari root repositori:

Mengemas lima zip skill untuk diunggah ke claude.ai.
  1. kemas.sh menyusun tiap folder skill menjadi zip yang berisi SKILL.md, README.md, LICENSE, references/, dan scripts/.
  2. Kelima zip ini diunggah satu per satu lewat Settings → Capabilities → Skills.

Unggah kelimanya. Di claude.ai, reverse-vcbd mencari vcbd di /mnt/skills/user/vcbd/. Bila akun Anda sudah punya skill bernama sama, hapus dulu versi lamanya supaya tidak ada dua versi yang berbeda.

2.6 Bila salinan skill ganda

Skill yang diunggah ke akun claude.ai ikut tersinkron ke Claude Code dan tampil sebagai anthropic-skills:<nama>, di samping salinan lokal. Bila versinya berbeda, agen bisa memakai versi yang salah. Solusi yang disarankan adalah menyamakan keduanya. Alternatifnya, blokir salinan sinkron di ~/.claude/settings.json:

{
  "permissions": {
    "deny": [
      "Skill(anthropic-skills:vcbd)",
      "Skill(anthropic-skills:coding-vcbd)",
      "Skill(anthropic-skills:review-vcbd)",
      "Skill(anthropic-skills:reverse-vcbd)",
      "Skill(anthropic-skills:reverse-web-vcbd)"
    ]
  }
}

2.7 Memeriksa instalasi

Tiga perintah berikut memastikan semua skrip valid secara sintaks dan uji regresi reverse-web-vcbd lulus:

$ cd ~/.claude/skills
$ for f in vcbd/scripts/*.sh coding-vcbd/scripts/*.sh; do bash -n "$f" && echo "OK $f"; done
$ for f in */scripts/*.py; do python3 -m py_compile "$f" && echo "OK $f"; done
$ python3 reverse-web-vcbd/uji/uji_regresi.py      # harus: 32/32 lulus

Anda akan melihat hasil uji regresi itu di Bab 7. Untuk sekarang, cukup pastikan tidak ada baris yang gagal.

2.8 Memperbarui dan mencopot

$ cd VCBD && git pull
$ for d in vcbd coding-vcbd review-vcbd reverse-vcbd reverse-web-vcbd; do
    rm -rf ~/.claude/skills/$d && cp -r skills/$d ~/.claude/skills/
  done

Proyek yang sudah menyalin skrip ke scripts/ tidak ikut terbarui otomatis. Salin ulang bila CHANGELOG.md menyebut ada perubahan skrip. Untuk mencopot, cukup hapus kelima folder skill. Berkas yang sudah lahir di proyek (docs/, CLAUDE.md, INDEX.md, scripts/) tidak tersentuh.

Rangkuman Bab 2
  • VCBD hanya butuh Python 3.8+ dan Bash; dependensi lain opsional.
  • Pasang kelima skill sekaligus dan biarkan foldernya bersebelahan.
  • Salin skrip gerbang ke scripts/ proyek agar proyek bisa memeriksa dirinya sendiri.
  • Jalankan setiap skrip gerbang dari root proyek.
